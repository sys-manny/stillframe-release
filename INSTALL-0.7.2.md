# Getting started with Stillframe 0.7.2

1. [Download the Windows x64 portable ZIP](https://github.com/sys-manny/stillframe-release/releases/download/v0.7.2/Stillframe-0.7.2-win-x64.zip).
2. Extract the complete ZIP to a writable folder.
3. Run `Launch.cmd` and choose **Import** to add a folder.

The app stores its portable profile under `app/Stillframe` beside the executable. Keep the extracted files together. Moving the whole folder keeps the profile with the app. Keep a backup of that profile and your media before replacing or removing an older copy.

This release starts with a fresh profile. If you're coming from 0.6.4, import the media folders again. Tags and catalog migration are outside this release. Stillframe leaves your originals in place when you import a folder.

This build is unsigned. Windows may show a SmartScreen reputation warning. The [release page](https://github.com/sys-manny/stillframe-release/releases/tag/v0.7.2) includes a SHA-256 checksum file so you can verify the download.
