# Install and upgrade — Stillframe 0.8.0

1. Extract the entire Stillframe-0.8.0-win-x64 folder to a writable local NTFS or exFAT drive.
2. Keep Stillframe.exe, app and runtime-notices together. Open Stillframe.exe normally; no installer or administrator launch is required.
3. To transfer existing data, open the earlier Stillframe copy and choose Preferences → Backup & import. Select Settings, Thumbnails, Tags and People data for a complete backup, choose a new .library file, review and select Back up and close.
4. Open the new final copy. In Backup & import, select the archive and desired categories, review and choose Import and restart. Categories left off retain their current values; selected categories replace their saved data. The previous complete profile is retained for recovery.
5. If a registered media folder is missing on the new drive/PC, use Locate. The archive contains saved application data, not the original photos/videos.

Release packaging does not move, copy or purge your personal profile automatically. Existing closed-profile copying remains supported: preserve the complete app/Stillframe folder and every file/subfolder together. No Windows file association or other OS integration is installed.

## Manual tags

Select photos/videos and use **Details → Tags**. Commas separate tags. Tag names are shared across libraries; type at least three matching characters to see suggestions in Add tags or Filter tags. Tags live in the portable profile and do not modify original media.

## Floating player

Open a photo/video and select the pop-out icon. Drag to move, resize while preserving aspect ratio, and use hover controls for Previous/Next and Return to viewer. Photos use zoom/Fit in the same area as video volume. Clicking the video viewport toggles play/pause.
