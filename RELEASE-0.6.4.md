# Stillframe 0.6.4

Windows x64 beta for browsing, organizing and tagging photos and videos. Application source remains private.

## Downloads

Download **Stillframe-0.6.4-Setup.exe** and **Stillframe-0.6.4-win-x64.zip** into the same folder, then run setup. Or extract the complete ZIP and run its root Stillframe.exe for portable use. The .NET Desktop runtime is included.

Optional visual tag suggestions need both visEngine SFA parts. The optional RTX SFA enables supported NVIDIA GPU acceleration. Neither addon is required for the base application. Keep selected addons beside setup.

See INSTALL-0.6.4.md, KNOWN-LIMITATIONS-0.6.4.md and SHA256SUMS.txt in the release assets.

## Highlights

- Guided Location → Options → Review → Install workflow, visible progress and a desktop shortcut selected by default.
- Graphical folder-tile Move workflow, concise review and explicit conflict choices.
- Corrections to tag editing, move/rename/folder creation, close handling, dark-theme export and extension sorting.
- Consistent viewer controls with permanent previous/next navigation and separate ten-second video seeks.
- Play-through automatically starts the selected video and continues through the folder; multi-selected videos form their own ordered sequence.
- Remembered volume from 0–150%, starting at 100%, without widening the volume slider.
- Conversion action aligned to the right; clearer Remove/delete empty wording.

## Validation and limits

The 17 scoped corrections received focused independent review. The frozen packaged application also completed bounded generated-file/runtime checks and the installer completed no-install previews. This is a publication of those unchanged binaries, not a new build or a broad regression, fresh-PC installation, owner-media, provider or hardware-audio acceptance claim.

Automatic browsing remains saved-only. Browsing acceleration, idle CPU optimization and biometric features remain deferred. The app and installer are unsigned; Windows may show a SmartScreen warning. Keep backups and review file-operation previews.

**Before returning to 0.6.3, set volume to 100% or lower in 0.6.4.** The older validator rejects higher saved values. Portable copies can share your Windows-user settings and caches.
